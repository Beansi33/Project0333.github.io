# BoonesBot

BoonesBot is een AI-gestuurde reel-fabriek die positieve kennis, humor en waardevolle verhalen omzet in korte video-inhoud voor sociale media.

## Doel

- glimlachen verspreiden
- mensen verbinden
- positieve content inzetten voor impact en welzijn
- samenwerken aan een bewust en behulpzaam project

## Projectstatus

Deze repository functioneert als GitHub Pages-site voor BoonesBot.

## Lokale preview

Open `index.html` in een browser of gebruik een lokale webserver.

## Deployment

De site wordt automatisch gedeployed via GitHub Pages.
